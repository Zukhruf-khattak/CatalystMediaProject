# API Documentation & OpenAPI Notes

## Interactive Documentation
When the FastAPI backend is running, interactive OpenAPI specifications are available at:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc**: `http://localhost:8000/redoc`
- **Raw OpenAPI Schema**: `http://localhost:8000/openapi.json`

## Headers
- `X-Request-ID`: Every request accepts an optional incoming `X-Request-ID` header. If absent or invalid, the server automatically generates a UUIDv4 and returns it in the response headers.

## Error Format
All errors generated by the application return a standardized JSON structure:
```json
{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "The requested item was not found.",
    "request_id": "c83095d3-8be2-446a-93f5-749e7987dc34"
  }
}
```
